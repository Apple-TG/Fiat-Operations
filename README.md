# Fiat Operations AI

可直接部署到 GitHub Pages 的純前端網站。

## 使用方式
1. 將本資料夾內所有檔案上傳到 GitHub Repository 根目錄。
2. GitHub Pages 設定為 main / root。
3. 開啟 Pages 網址即可使用。

## 已包含
- Dashboard
- Robot 商戶餘額解析
- 7 日提款／代收 Excel、CSV 上傳
- Pending 表格分析
- 結算話術生成
- 主管回報生成
- 本機自動儲存
- JSON 備份與還原

Excel 解析使用 SheetJS 0.20.3 瀏覽器版。若公司網路阻擋 CDN，可將報表另存 CSV 再上傳。
